# ZenStay – Accommodation Booking Platform

## 🚀 Overview
ZenStay is a full-stack accommodation booking platform where users can explore, list, and book properties.

## 🛠 Tech Stack
- Frontend: React.js, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB

## ✨ Features
- User authentication (Login/Signup)
- Property listing and booking system
- Responsive UI for all devices
- RESTful API integration
